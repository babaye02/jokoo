## 📋 Checklist rapide pour App Store Connect

### iOS — App Store Connect
1. **Sign in** → https://appstoreconnect.apple.com
2. Sélectionnez l'app **Jokoo**
3. Menu de gauche → **Pricing and Availability**
4. Section **Availability** → Cliquez sur **Edit Countries or Regions**
5. Cochez les **27 pays** listés dans les Tiers 1 à 4
6. Décochez tous les autres pays
7. Cliquez **Done** puis **Save**

### Android — Google Play Console
1. **Sign in** → https://play.google.com/console
2. Sélectionnez **Jokoo**
3. Menu de gauche → **Production** → **Countries / regions**
4. Cliquez **Add countries / regions**
5. Cochez les **27 pays** identiques
6. **Save changes**

## 💡 Notes stratégiques

### Prix par pays
- **Afrique de l'Ouest (Tier 1-3)** : Gratuit (freemium via Jokoo Pro).
- **Diaspora (Tier 4)** : Gratuit. Les utilisateurs paient via web pour l'abonnement Pro.

### Langue de l'App Store listing
- **Français (fr-FR)** : par défaut pour tous les pays.
- **Anglais (en-US)** : ajouter en secondaire pour GB, US, CA, NL.
- **Wolof (wo)** : non supporté par Apple. Utiliser Français comme fallback.

### Support technique par pays
- **Sénégal + UEMOA** : Wave, Orange Money, cartes bancaires.
- **Diaspora** : Cartes bancaires uniquement (via Stripe côté web).

### Modération et fuseau horaire
- **Modération 24/7** requise pour la conformité Apple.
- Fuseau horaire Sénégal : **UTC+0** (Africa/Dakar). Étudier un roulement d'équipe pour couvrir Europe (UTC+1 à UTC+2) et US Est (UTC-5).
